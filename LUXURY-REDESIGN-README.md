# WELSTENFORDE — Luxury Editorial Redesign

Run `npm install` and `npm run dev` from this folder. The homepage is now deliberately short: cinematic hero, editorial shopping story, and animated luxury statement. Existing shop, apparel, jewellery, product details, wishlist, bag, checkout, lookbook and other routes remain.

## Video asset required
Place a licensed 6–12-second MP4 at `public/videos/welstenforde-campaign.mp4`. A still campaign image is used as a poster until a video is supplied. No AI-generated video was produced with this package.

## Commerce status
The supplied site uses client-side shopping state; a live payment gateway, server-side inventory, order processing and secure production checkout require backend/payment-provider integration.
