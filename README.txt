WELSTENFORDE — Responsive Luxury Fashion E-commerce Website

HOW TO RUN
1. Extract this ZIP folder.
2. Open index.html in a modern browser, or run a local static server from this folder.
3. Recommended: VS Code + Live Server.

PAGES INCLUDED
Home, Shop All, New Arrivals, Clothing, Jewellery, Collections, About Us, Contact Us, Product Details, Shopping Bag, Checkout, Sign In, Create Account, My Account & Orders, Wishlist, FAQ, Shipping, Returns & Refunds, Privacy Policy, Terms & Conditions, Size Guide.

FUNCTIONAL DEMO FEATURES
- All page navigation and footer links are connected.
- Responsive desktop and mobile navigation.
- Product listing, category filters and sorting.
- Product detail page with size selection and accordions.
- Add to bag, quantity controls, remove item and order summary.
- Wishlist saved in browser localStorage.
- Demo checkout flow and forms.
- FAQ accordions and newsletter/contact form feedback.

DESIGN SYSTEM
Rich Black #0B0A0A | Warm Ivory #F5F0E9 | Champagne Beige #BEA996 | Soft Black #1B1917 | Taupe Beige #AB9887 | Muted Beige #C9BCB1 | Light Cream #E1DBD3 | White #FFFFFF

NOTES
- Product photography is loaded from Unsplash URLs and Google Fonts are loaded online; internet access is needed for those remote assets.
- Cart, wishlist and demo interactions are browser-side only. No payment gateway, inventory system, customer database, shipping provider, authentication service or production backend is connected.
- Checkout is a front-end demonstration and does not charge a payment method or create a real order. Connect a secure commerce backend before launch.
